Print Working Directory: pwd -> prints the path to the working directory (where you currently are)
$ pwd <=
/c/Users/mikha


Change Directory: cd -> to change and move between folders
mikha@LENOVOV15IWL UCRT64 ~
$ cd Apple/ <=
mikha@LENOVOV15IWL UCRT64 ~/Apple
$ ls <=
MobileSync/

cd back up one directory
cd .. <=
$ cd ..
mikha@LENOVOV15IWL UCRT64 ~


Make Directory: mkdir -> create a new directory or directories


Manual: man -> gives information about ls


Touch: touch -> create a file or multiple files 


Remove: rm -> permanently removes file or files


Remove with force: rm-rf -> delete a directory (r = recursive, f = force)
